# رحلة المبرمجة في قطر 🧭

لعبة تعليمية لدرس **خطوات حل المشكلات** (الحوسبة وتكنولوجيا المعلومات – الصف التاسع)، مع **لوحة معلمة مباشرة** تعرض أسماء الطالبات ونقاطهن وإجاباتهن في السؤال الإبداعي.

## محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة الطالبات (الرحلة) |
| `teacher.html` | لوحة المعلمة |
| `api/submit.js` | يستقبل نتيجة كل طالبة تلقائيًا |
| `api/results.js` | يعرض النتائج للمعلمة (بعد إدخال رقمها السري) |
| `api/_redis.js` | الاتصال بقاعدة البيانات |

## خطوات النشر (مرة واحدة فقط)

### 1. GitHub
1. أنشئي مستودعًا جديدًا (New repository)، مثلًا باسم `qatar-coder`.
2. اضغطي **uploading an existing file** واسحبي **كل الملفات ومجلد `api`** كما هي.
3. اضغطي **Commit changes**.

### 2. Vercel
1. من [vercel.com](https://vercel.com) اختاري **Add New → Project** ثم **Import** المستودع.
2. في Framework Preset اختاري **Other**، واتركي باقي الإعدادات كما هي، ثم **Deploy**.

### 3. قاعدة البيانات (مجانية)
1. داخل المشروع في Vercel افتحي تبويب **Storage**.
2. اختاري **Create Database → Upstash for Redis** (الخطة المجانية).
3. اربطيها بالمشروع (**Connect Project**). سيضيف Vercel مفاتيح الاتصال تلقائيًا.

### 4. الرقم السري للمعلمة
1. **Settings → Environment Variables**.
2. أضيفي متغيرًا اسمه `TEACHER_KEY` وقيمته رقم سري تختارينه (مثل `4729`)، ثم **Save**.

### 5. إعادة النشر
**Deployments** ← النقاط الثلاث بجانب آخر نشر ← **Redeploy**، لأن الإعدادات الجديدة لا تُطبَّق إلا بعد إعادة النشر.
