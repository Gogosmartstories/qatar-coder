# رحلة المبرمجة في قطر 🧭

لعبة تعليمية لدرس **خطوات حل المشكلات** (الحوسبة وتكنولوجيا المعلومات – الصف التاسع)، مع **لوحة معلمة مباشرة**. النتائج تُحفظ في **Google Sheets** مجانًا.

## محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة الطالبات (الرحلة) |
| `teacher.html` | لوحة المعلمة |
| `config.js` | تلصقين فيه رابط Google Apps Script |
| `apps-script.gs` | الكود الذي تلصقينه في Google Sheets (لا يُرفع إلى GitHub) |

## الخطوة 1: Google Sheets و Apps Script

1. أنشئي جدول Google Sheets جديدًا، وسمّيه مثلًا «نتائج رحلة المبرمجة».
2. من القائمة: **الإضافات ← Apps Script** (Extensions ← Apps Script).
3. احذفي الكود الموجود، والصقي محتوى ملف `apps-script.gs` كاملًا.
4. في السطر `const TEACHER_KEY = '4729';` غيّري `4729` إلى رقمك السري.
5. اضغطي 💾 **حفظ**.
6. اضغطي **نشر ← نشر جديد** (Deploy ← New deployment):
   - من ⚙️ بجانب «تحديد النوع» اختاري **تطبيق ويب** (Web app).
   - **التنفيذ باسم** (Execute as): **أنا** (Me).
   - **من لديه حق الوصول** (Who has access): **أي شخص** (Anyone).
   - اضغطي **نشر** (Deploy).
7. سيطلب Google **الإذن**: اختاري حسابك ← **Advanced (متقدم)** ← **Go to ... (unsafe)** ← **Allow**.
   هذا طبيعي لأن الكود كتبتِه أنتِ ولم يراجعه Google.
8. انسخي **رابط تطبيق الويب**، وهو ينتهي بـ `/exec`.

## الخطوة 2: GitHub

1. افتحي ملف `config.js` في المستودع ← ✏️ تعديل.
2. استبدلي `PASTE_YOUR_APPS_SCRIPT_URL_HERE` بالرابط الذي نسختِه (بين علامتي ' ').
3. ارفعي أيضًا `index.html` و`teacher.html` الجديدين بدل القديمين.
4. يمكنك حذف مجلد `api` القديم إن وُجد (لم يعد مستخدمًا).
5. **Commit changes**. سيعيد Vercel النشر تلقائيًا خلال ثوانٍ.

## الروابط

- **للطالبات:** `https://اسم-مشروعك.vercel.app`
- **لكِ فقط:** `https://اسم-مشروعك.vercel.app/teacher.html` ← أدخلي رقمك السري
- **الجدول:** تظهر النتائج أيضًا في ورقة «النتائج» داخل Google Sheets.
